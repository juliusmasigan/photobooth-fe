# Remote control relay (camera backend)

The capture screen shows a QR code linking to `/remote/<sessionId>`. The phone and the
booth never talk directly: both connect to a relay socket on the camera backend, which
forwards messages within a session. This file specifies what the backend must provide.

## Endpoint

```
ws://<backend>/ws/remote/{sessionId}?role=booth|remote
```

- Sockets are grouped by `sessionId` (a UUID generated by the booth each time it opens the capture screen).
- Messages from the **booth** are forwarded to every **remote** in the session.
- Messages from a **remote** are forwarded to the **booth** only.
- Nothing is echoed back to its sender.
- Limit each session to a handful of remotes (e.g. 4); reject extras with close code `1008`.

## Presence events (sent by the relay)

| To      | Message                                   | When                                      |
|---------|-------------------------------------------|-------------------------------------------|
| booth   | `{"type":"remote_joined","count":N}`      | a remote connects (N = remotes now)       |
| booth   | `{"type":"remote_left","count":N}`        | a remote disconnects                      |
| remotes | `{"type":"booth_joined"}`                 | booth connects; also sent to a newly connecting remote if the booth is already there |
| remotes | `{"type":"booth_left"}`                   | booth disconnects (room is then removed)  |

## App messages (forwarded as-is)

Remote → booth:

```json
{"type":"remote_hello"}
{"type":"remote_command","command":"shutter"}
{"type":"remote_command","command":"set_mode","mode":"collage"}
{"type":"remote_command","command":"set_filter","filter":"sunglasses"}
```

Booth → remotes:

```json
{"type":"booth_state","mode":"still","modes":[["still","Still Photo"],...],
 "isCapturing":false,"isProcessing":false,"countdown":3,"remainingShots":null,
 "filters":[{"id":"none","name":"None","kind":"none"},...],"activeFilter":"none"}
```

## Reference implementation (FastAPI)

```python
from fastapi import WebSocket, WebSocketDisconnect

MAX_REMOTES = 4
rooms: dict[str, dict] = {}  # sessionId -> {"booth": WebSocket | None, "remotes": set[WebSocket]}


@app.websocket("/ws/remote/{session_id}")
async def remote_relay(ws: WebSocket, session_id: str, role: str = "remote"):
    room = rooms.setdefault(session_id, {"booth": None, "remotes": set()})
    if role == "remote" and len(room["remotes"]) >= MAX_REMOTES:
        await ws.close(code=1008)
        return
    await ws.accept()

    if role == "booth":
        if room["booth"] is not None:
            await room["booth"].close()
        room["booth"] = ws
        for r in list(room["remotes"]):
            await r.send_json({"type": "booth_joined"})
    else:
        room["remotes"].add(ws)
        if room["booth"] is not None:
            await ws.send_json({"type": "booth_joined"})
            await room["booth"].send_json({"type": "remote_joined", "count": len(room["remotes"])})

    try:
        while True:
            text = await ws.receive_text()
            if role == "booth":
                for r in list(room["remotes"]):
                    await r.send_text(text)
            elif room["booth"] is not None:
                await room["booth"].send_text(text)
    except WebSocketDisconnect:
        pass
    finally:
        if role == "booth":
            if room["booth"] is ws:
                room["booth"] = None
                for r in list(room["remotes"]):
                    await r.send_json({"type": "booth_left"})
                rooms.pop(session_id, None)
        else:
            room["remotes"].discard(ws)
            if room["booth"] is not None:
                await room["booth"].send_json({"type": "remote_left", "count": len(room["remotes"])})
            if room["booth"] is None and not room["remotes"]:
                rooms.pop(session_id, None)
```

Production code should wrap the per-socket sends in `try/except` so one dead socket
doesn't abort a broadcast.

## Frontend configuration

- `REACT_APP_REMOTE_WEBSOCKET_URL` — relay base URL (defaults to the camera socket URL with `/ws` → `/ws/remote`).
- `REACT_APP_REMOTE_BASE_URL` — this app's address as a phone on the LAN sees it, used in the QR code.
  The kiosk browser often runs on `localhost`, which a phone can't reach. Defaults to `window.location.origin`.
- Phones also load the live preview from `REACT_APP_API_BASE_URL/api/stream`, so the backend must be reachable from the LAN.
